02 / 3차원 주응력

σ1 ≥ σ2 ≥ σ3
절대 최대전단응력

면외 주응력 0을 포함해 정렬합니다. 항복판별에 쓰는 최대전단응력은 (σ1 − σ3)/2이며, 면내 반지름 R과 다를 수 있습니다.

응력변환식과 각도 정의
σx′ = C + ((σx − σy)/2) cos 2θ + τxy sin 2θ
σy′ = C − ((σx − σy)/2) cos 2θ − τxy sin 2θ
τx′y′ = −((σx − σy)/2) sin 2θ + τxy cos 2θ
θp = ½ atan2(2τxy, σx − σy)

atan2는 응력의 부호에 맞는 사분면을 선택합니다. θp는 면내 최대주응력 σa 방향이며, 최소주응력 방향은 θp + 90°입니다. R = 0이면 모든 면내 방향이 주응력 방향이므로 유일한 θp가 없습니다.

면내 최대전단면은 θp ± 45°. 위 버튼은 τx′y′ = +R인 방향을 선택합니다. 회전 응력요소는 방향과 응력 부호를 나타내며 실제 변형 형상을 뜻하지 않습니다.

적용 범위와 항복경계 읽기

이 도구는 등방성 연성재료의 초기 항복을 비교하는 학습용 계산기입니다. 인장·압축 항복강도가 같다고 가정하며, 취성파괴·피로·좌굴·이방성·경화는 계산하지 않습니다. 실제 설계의 적합성이나 안전을 보증하지 않습니다.

그래프의 축 σa, σb는 면내 두 주응력입니다. 경계는 전체 주응력 평면을 나타내고, 현재 점은 σa ≥ σb로 정렬되어 표시됩니다. Tresca 경계는 max(|σa|, |σb|, |σa−σb|) = σY, von Mises 경계는 σa² − σaσb + σb² = σY²입니다.

‘항복조건 초과’는 주어진 탄성 응력값이 기준을 넘는다는 뜻입니다. 항복 이후 실제 응력 재분배나 소성변형량은 이 모델로 예측하지 않습니다. 안전율은 현재 응력에서 동일 비율로 하중을 증가시킬 때의 항복 도달 배율입니다. 무응력 상태에서는 ∞로 표시합니다.

전변형이론의 의미와 적용 범위

전변형이론은 현재의 전체 변형률이 현재 편차응력에 비례한다고 보는 소성 이론입니다. 비례하중처럼 응력 성분의 비율이 크게 변하지 않는 경우를 설명하는 데 적합합니다.

여기서는 교재 식에 따라 소성 비압축성, 즉 ε1 + ε2 + ε3 = 0을 가정합니다. 일반적인 탄성변형까지 분리해 계산하려면 탄성계수와 포아송비를 추가한 탄소성 모델이 필요합니다.
